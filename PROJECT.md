## 1. Overview & Arsitektur

### 1.1 Deskripsi Singkat

World Cup Simulator adalah aplikasi web yang memungkinkan pengguna mensimulasikan turnamen piala dunia dalam format **what-if**. Pengguna dapat:

- Mendaftarkan tim ke dalam grup
- Menjalankan fase grup secara round-robin
- Menginput hasil pertandingan secara bebas
- Melihat klasemen real-time
- Melanjutkan ke fase knockout (sistem gugur)
- Melihat bracket knockout

## 3. Database Schema (Prisma)

### 3.1 ERD (Entity Relationship Diagram)

```
┌──────────────────┐       ┌──────────────────────────────┐
│       Team       │       │            Match              │
├──────────────────┤       ├──────────────────────────────┤
│ id        INT PK │       │ id          INT PK            │
│ name      TEXT   │       │ teamAId     INT FK → Team     │
│ code      TEXT   │◄──────│ teamBId     INT FK → Team     │
│ group     TEXT   │       │ scoreA      INT? (nullable)   │
│ createdAt DATETIME│      │ scoreB      INT? (nullable)   │
│ updatedAt DATETIME│      │ phase       ENUM (group/knockout)│
└──────────────────┘       │ status      ENUM (scheduled/finished)│
                           │ round       INT?              │
                           │ bracketPos  TEXT?             │
                           │ createdAt   DATETIME          │
                           │ updatedAt   DATETIME          │
                           └──────────────────────────────┘
```

### 3.2 Schema Prisma (`prisma/schema.prisma`)

```prisma
generator client {
  provider = "prisma-client-js"
}

datasource db {
  provider = "mysql"
  url      = env("DATABASE_URL")
}

model Team {
  id        Int      @id @default(autoincrement())
  name      String
  code      String   @unique        // e.g. "BRA", "ARG"
  group     String                   // e.g. "A", "B", "C"
  createdAt DateTime @default(now())
  updatedAt DateTime @updatedAt

  // Relations
  matchesAsTeamA Match[] @relation("TeamA")
  matchesAsTeamB Match[] @relation("TeamB")

  @@index([group])
}

model Match {
  id         Int      @id @default(autoincrement())
  teamAId    Int
  teamBId    Int
  scoreA     Int?                      // null = belum dimainkan
  scoreB     Int?                      // null = belum dimainkan
  phase      String   @default("group") // "group" | "knockout"
  status     String   @default("scheduled") // "scheduled" | "finished"
  round      Int?                      // 1, 2, 3 untuk grup; 1=QF, 2=SF, 3=Final untuk knockout
  bracketPos String?                   // e.g. "QF1", "SF1", "F" — posisi di bracket
  createdAt  DateTime @default(now())
  updatedAt  DateTime @updatedAt

  // Relations
  teamA Team @relation("TeamA", fields: [teamAId], references: [id])
  teamB Team @relation("TeamB", fields: [teamBId], references: [id])

  @@index([phase])
  @@index([status])
  @@index([phase, status])
}
```

### 3.3 Penjelasan Design Decision

| Keputusan | Alasan |
|-----------|--------|
| `group` sebagai field di Team, bukan tabel terpisah | Jumlah grup tetap (A-H), tidak perlu relasi terpisah, menyederhanakan query |
| `scoreA`/`scoreB` nullable | null menandakan pertandingan belum dimainkan, sekaligus menghilangkan kebutuhan field `status` terpisah — tapi tetap ada `status` untuk explicit filtering |
| `phase` field di Match | Memudahkan filter: GET /matches?phase=group |
| `round` field | Untuk fase grup: ronde 1, 2, 3 (round-robin). Untuk knockout: 1=Quarter-final, 2=Semi-final, 3=Final |
| `bracketPos` | Menyimpan posisi di bracket knockout (QF1, QF2, SF1, SF2, F) untuk memudahkan rendering frontend |
| MySQL | Relational DB populer, Prisma support penuh, cocok untuk skala tugas ini |
| `code` unique di Team | Mencegah duplikat kode tim |

## 5. Autentikasi JWT

### 5.1 Flow Autentikasi

```
┌─────────┐                    ┌─────────┐                ┌──────────┐
│  Client  │                    │ Express │                │  Prisma  │
└────┬─────┘                    └────┬────┘                └────┬─────┘
     │                               │                          │
     │  POST /login                  │                          │
     │  { password: "rahasia123" }   │                          │
     │──────────────────────────────►│                          │
     │                               │                          │
     │                               │  Compare with            │
     │                               │  ADMIN_PASSWORD          │
     │                               │  from .env               │
     │                               │                          │
     │                               │  IF match:               │
     │                               │    Generate JWT          │
     │                               │    { role: "admin" }     │
     │                               │    Sign with JWT_SECRET  │
     │                               │                          │
     │  200 { token: "eyJ..." }      │                          │
     │◄──────────────────────────────│                          │
     │                               │                          │
     │  POST /teams                  │                          │
     │  Authorization: Bearer <jwt>  │                          │
     │──────────────────────────────►│                          │
     │                               │  authMiddleware:         │
     │                               │    Verify JWT            │
     │                               │    Attach req.admin      │
     │                               │                          │
     │                               │  IF valid → continue     │
     │                               │  IF invalid → 401        │
     │                               │                          │
     │  201 { team data }            │                          │
     │◄──────────────────────────────│                          │
```

### 5.2 JWT Payload

```json
{
  "role": "admin",
  "iat": 1719000000,
  "exp": 1719086400
}
```

Minimal payload: `role: "admin"`. Bisa ditambah field lain jika diperlukan.

### 5.3 Middleware (`src/middleware/auth.js`)

```javascript
// Pseudocode
function authMiddleware(req, res, next) {
  // 1. Ambil header Authorization
  const authHeader = req.headers.authorization;

  // 2. Cek format "Bearer <token>"
  if (!authHeader || !authHeader.startsWith("Bearer ")) {
    return res.status(401).json({ error: "Token tidak ditemukan" });
  }

  const token = authHeader.split(" ")[1];

  // 3. Verify JWT
  try {
    const decoded = jwt.verify(token, process.env.JWT_SECRET);
    req.admin = decoded;
    next();
  } catch (err) {
    return res.status(401).json({ error: "Token tidak valid atau expired" });
  }
}
```

### 6.9 POST /tournament/setup

**Auth:** ✅ Bearer Token

**Logic:**
1. Ambil semua tim dari database
2. Kelompokkan berdasarkan grup
3. Untuk setiap grup, buat semua kombinasi pertandingan round-robin
4. **Idempotent:** Cek apakah jadwal sudah ada sebelum membuat baru

**Round-Robin Formula:**
- Untuk grup dengan N tim, jumlah pertandingan = N × (N-1) / 2
- Contoh: 4 tim per grup = 6 pertandingan per grup

**Response 200 — Berhasil:**
```json
{
  "message": "Jadwal fase grup berhasil dibuat",
  "matchesCreated": 48
}
```

**Response 200 — Sudah ada (idempotent):**
```json
{
  "message": "Jadwal fase grup sudah ada",
  "matchesCreated": 0
}
```

**Response 400 — Tim kurang:**
```json
{
  "error": "Setiap grup harus memiliki minimal 2 tim"
}
```

### 6.10 POST /tournament/advance

**Auth:** ✅ Bearer Token

**Logic:**
1. Cek semua match fase grup sudah `finished`
2. Hitung klasemen setiap grup
3. Ambil top 2 dari setiap grup
4. Buat bracket knockout:
   - 8 grup → 16 tim → Quarter-final (8 match) → Semi-final (4 match) → Final (2 match) → Champion
   - 4 grup → 8 tim → Quarter-final (4 match) → Semi-final (2 match) → Final

**Bracket Mapping (8 grup):**
```
QF1: 1A vs 2B
QF2: 1C vs 2D
QF3: 1E vs 2F
QF4: 1G vs 2H
QF5: 1B vs 2A
QF6: 1D vs 2C
QF7: 1F vs 2E
QF8: 1H vs 2G

SF1: Winner QF1 vs Winner QF2
SF2: Winner QF3 vs Winner QF4
SF3: Winner QF5 vs Winner QF6
SF4: Winner QF7 vs Winner QF8

F1: Winner SF1 vs Winner SF2
F2: Winner SF3 vs Winner SF4

FINAL: Winner F1 vs Winner F2
```

**Response 200:**
```json
{
  "message": "Fase knockout berhasil dibuat",
  "bracket": {
    "quarterFinals": 8,
    "semiFinals": 4,
    "final": 2,
    "champion": 1
  }
}
```

**Response 400 — Grup belum selesai:**
```json
{
  "error": "Masih ada pertandingan fase grup yang belum selesai",
  "unfinishedMatches": 12
}
```

## 7. Business Logic — Detail Implementasi

### 7.1 Standings Calculation (`src/utils/standings.js`)

```javascript
/**
 * Hitung klasemen dari array pertandingan
 * @param {Array} matches - Array of finished matches dalam satu grup
 * @param {Array} teams - Array of teams dalam grup tersebut
 * @returns {Array} Standings sorted by points (desc), then goalDiff (desc), then goalsFor (desc)
 */
function calculateStandings(matches, teams) {
  // 1. Inisialisasi stats untuk setiap tim
  const stats = {};
  for (const team of teams) {
    stats[team.id] = {
      team: team.name,
      code: team.code,
      played: 0,
      won: 0,
      drawn: 0,
      lost: 0,
      goalsFor: 0,
      goalsAgainst: 0,
      goalDiff: 0,
      points: 0,
    };
  }

  // 2. Proses setiap match yang sudah finished
  for (const match of matches) {
    if (match.status !== "finished") continue;

    const a = stats[match.teamAId];
    const b = stats[match.teamBId];

    if (!a || !b) continue;

    // Update played
    a.played++;
    b.played++;

    // Update goals
    a.goalsFor += match.scoreA;
    a.goalsAgainst += match.scoreB;
    b.goalsFor += match.scoreB;
    b.goalsAgainst += match.scoreA;

    // Determine result
    if (match.scoreA > match.scoreB) {
      // Team A menang
      a.won++;
      a.points += 3;
      b.lost++;
    } else if (match.scoreA < match.scoreB) {
      // Team B menang
      b.won++;
      b.points += 3;
      a.lost++;
    } else {
      // Seri
      a.drawn++;
      a.points += 1;
      b.drawn++;
      b.points += 1;
    }
  }

  // 3. Hitung goal difference
  for (const id in stats) {
    stats[id].goalDiff = stats[id].goalsFor - stats[id].goalsAgainst;
  }

  // 4. Sort: points DESC, goalDiff DESC, goalsFor DESC
  const sorted = Object.values(stats).sort((a, b) => {
    if (b.points !== a.points) return b.points - a.points;
    if (b.goalDiff !== a.goalDiff) return b.goalDiff - a.goalDiff;
    return b.goalsFor - a.goalsFor;
  });

  // 5. Assign rank
  sorted.forEach((entry, index) => {
    entry.rank = index + 1;
  });

  return sorted;
}
```

### 7.2 Round-Robin Match Generation

```javascript
/**
 * Generate semua pertandingan round-robin untuk satu grup
 * @param {Array} teams - Array of team IDs dalam grup
 * @returns {Array} Array of { teamAId, teamBId } pairs
 */
function generateRoundRobin(teams) {
  const matches = [];
  for (let i = 0; i < teams.length; i++) {
    for (let j = i + 1; j < teams.length; j++) {
      matches.push({
        teamAId: teams[i].id,
        teamBId: teams[j].id,
      });
    }
  }
  return matches;
}
```

### 7.3 Knockout Bracket Generation

```javascript
/**
 * Generate bracket knockout dari standings semua grup
 * @param {Object} standingsByGroup - { "A": [...standings], "B": [...standings] }
 * @returns {Array} Array of knockout matches
 */
function generateKnockoutBracket(standingsByGroup) {
  const groups = Object.keys(standingsByGroup).sort();
  const matches = [];

  // Ambil top 2 dari setiap grup
  const qualified = [];
  for (const group of groups) {
    const sorted = standingsByGroup[group];
    qualified.push({ ...sorted[0], group }); // rank 1
    qualified.push({ ...sorted[1], group }); // rank 2
  }

  // Bracket pairing (contoh untuk 8 grup = 16 tim)
  // QF: 1A vs 2B, 1C vs 2D, 1E vs 2F, 1G vs 2H
  //     1B vs 2A, 1D vs 2C, 1F vs 2E, 1H vs 2G
  const half = qualified.length / 2;
  for (let i = 0; i < half; i++) {
    const team1 = qualified[i];        // 1st place dari grup i
    const team2 = qualified[half + (half - 1 - i)]; // 2nd place dari grup mirrored
    matches.push({
      teamAId: team1.teamId,
      teamBId: team2.teamId,
      phase: "knockout",
      round: 1,
      bracketPos: `QF${i + 1}`,
    });
  }

  // Semi-finals (placeholder, teams TBD)
  for (let i = 0; i < half / 2; i++) {
    matches.push({
      teamAId: null, // TBD — diisi saat QF selesai
      teamBId: null,
      phase: "knockout",
      round: 2,
      bracketPos: `SF${i + 1}`,
    });
  }

  // Final
  matches.push({
    teamAId: null,
    teamBId: null,
    phase: "knockout",
    round: 3,
    bracketPos: "F",
  });

  return matches;
}
```

### 7.4 Advancing Knockout Winners

Ketika user menginput hasil pertandingan knockout, sistem harus otomatis mengisi team di babak berikutnya:

```javascript
/**
 * Setelah input hasil match knockout, propagate winner ke next round
 */
async function propagateWinner(matchId, prisma) {
  const match = await prisma.match.findUnique({ where: { id: matchId } });

  if (match.phase !== "knockout" || match.status !== "finished") return;

  const winnerId = match.scoreA > match.scoreB ? match.teamAId : match.teamBId;

  // Tentukan match berikutnya berdasarkan bracketPos
  const nextMatchMapping = {
    QF1: { matchBracketPos: "SF1", side: "teamAId" },
    QF2: { matchBracketPos: "SF1", side: "teamBId" },
    QF3: { matchBracketPos: "SF2", side: "teamAId" },
    QF4: { matchBracketPos: "SF2", side: "teamBId" },
    // ... dst
    SF1: { matchBracketPos: "F", side: "teamAId" },
    SF2: { matchBracketPos: "F", side: "teamBId" },
  };

  const next = nextMatchMapping[match.bracketPos];
  if (!next) return; // Final, tidak ada next

  await prisma.match.updateMany({
    where: {
      bracketPos: next.matchBracketPos,
      phase: "knockout",
    },
    data: {
      [next.side]: winnerId,
    },
  });
}
```
